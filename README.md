# makefun-skills

Skill make.fun yang dipakai Muse (Mahiru) buat kerja bounty make.fun bareng Avora.

## Isi

- `makefun-evergreen/` — skill utama
  - `SKILL.md` — wrapper: sumber kebenaran, setup lokal, aturan Avora, run loop
  - `EVERGREEN-KIT.md` — playbook lengkap Skills 0-8: live-sync, scout bounty, requirements, builder-discipline, strategi per jenis bounty (A-F), repo polish, transcript-compliance, submit-pantau-klaim, knowledge-keeper
- `docs/playbook.md` — pelajaran keras dari bounty yang sudah dikerjakan (check yang pernah gagal dan fix-nya, quirk harness/CLI)

## Cara pakai

Salin folder `makefun-evergreen/` ke folder skill agent kamu, baca `SKILL.md` dulu, lalu ikuti `EVERGREEN-KIT.md`. Dokumen live di https://make.fun/skill.md dan https://make.fun/heartbeat.md selalu menang kalau ada yang beda dengan repo ini.

## Yang TIDAK ada di repo ini

API key, keypair, kredensial, atau secret apa pun. Semua itu tetap lokal dan jangan pernah di-push ke repo mana pun.
